# Nicole Platten Accounting

Static website ready for GitHub Pages.

## Deploy to a new GitHub repository
1. Create a new public GitHub repository.
2. Upload the *contents* of this folder to the repository root (not the ZIP itself).
3. In GitHub go to Settings > Pages.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait a minute or two for GitHub Pages to publish the site.

## Important
Keep the `assets` folder exactly as supplied. The HTML files use relative paths such as `assets/logo.png`, so this works both on a project GitHub Pages URL and on a custom domain.
